# GUI-calculator

Author: Veerpal Shah

A simple calculator capable of performing multiple operations developed using the Swing Framework. 
## Demo Video
 [YouTube](https://youtu.be/R8f7-vwP-Fc).


This is a simple Reverse Polish Notation (RPN) calculator implemented in Java. The calculator allows for basic arithmetic operations on natural numbers. It uses a model-view-controller (MVC) architecture and supports operations like addition, subtraction, multiplication, and division with natural numbers.

## Features

- **RPN (Reverse Polish Notation)**: Operations are performed using RPN, where the operands are entered before the operator.
- **Two Operand System**: The calculator maintains two operands, and operations are always performed on these two.
- **Natural Number Support**: Operates exclusively on natural numbers (i.e., non-negative integers).
- **Basic Operations**:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`)
  - Power (`^`)
  - Root (`√`)
- **Interface Features**:
  - Clear: Resets the bottom operand to zero.
  - Swap: Exchanges the values of the two operands.
  - Enter: Copies the bottom operand to the top operand.
  - Division: Divides the top operand by the bottom operand, displaying the quotient and remainder.

## Setup and Installation
Tested on VSCode
### Clone the Repository
To clone this repository to your local machine, run:
  ```bash
  git clone https://github.com/your-username/GUI-calculator.git
  ```
### Run the Program
To run this program on your machine, run:

  ```bash
  java -jar NaturalNumberCalculator.jar
  ```
